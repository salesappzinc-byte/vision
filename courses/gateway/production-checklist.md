# Production and instructor checklist

**Status of the course files:** Written draft, 7 November 2026. Not recorded. Not piloted. Not published.

Use this list before any recording is treated as ready. Checking a box here does not publish the course. The website, captions file, and pilot notes do not exist yet.

Index: [index.md](index.md).

## Before recording

- [ ] Read all seven lesson files and the toolkit against [VISION.md](../../VISION.md). Beginners, no earnings promise, no fake customer, no sample price.
- [ ] Confirm the script never names a chat vendor as the only option.
- [ ] Confirm lesson 5 still contains no web address. The presenter must open a real page on the day.
- [ ] Prepare sample labels only (Shop A, Shop B, Shop C, or the book-swap story). No real client file on the machine used to record.
- [ ] Turn off send, post, pay, and file-sync in the tool you demonstrate. Show that they are off.
- [ ] If a practice box on the future site does not exist, say so in the spoken open. Do not point at an empty button.

## Recording

- [ ] Record lesson 1 through lesson 7 as separate pieces so a learner can rest.
- [ ] Speak the narration. Do not skip the fictional label on Sam.
- [ ] Lesson 5: open a real public page, copy the title and address from the browser on camera, and mark one claim "not on the page" or "does not match".
- [ ] Do not record a checkout, a payout, a password, or an auto-send.
- [ ] Keep each piece a single sitting. Do not add a "day 1 of 7" frame.

## Captions and the written page

- [ ] Caption each recording in the same international English as the script. Do not leave the only copy of a step inside the video.
- [ ] Put the copy-ready prompts on the page as text, not only as speech.
- [ ] After lesson 5 is recorded, store the real title and address used on camera in the production notes, separate from the learner template, so a later editor does not invent one.

## Rights

- [ ] Music, images, and screen recordings are ones you can use. No customer's face. No cloned voice.
- [ ] Sam Okonkwo and the shops stay labelled fictional.
- [ ] Tool screens change. Note the tool and the month you recorded. Do not imply that screen is the only tool.

## Usability pilot

Not done. When it happens:

- [ ] At least a few complete beginners try the written lessons without you in the room. This checklist does not set how many.
- [ ] Watch where they paste a secret, send an email, or accept a tool's "verified".
- [ ] Ask whether the bookkeeping example blocks anyone who needed the personal path. Fix the draft if it does.
- [ ] Ask whether lesson 7 feels like a sales push. Soften it if they say yes.
- [ ] Record what you saw. Do not convert that into a success rate for marketing.

## Source and tool refresh

- [ ] Before a later recording, open lesson 5's demonstrated page again. If it moved, demonstrate a different real page. Do not keep a dead address in the spoken lesson.
- [ ] Re-read the do-not-paste and disclosure lines against the founder vision. Do not add a legal claim for all countries.
- [ ] If a deeper video, website, or automation course becomes real, change lesson 7 from "not available" to a factual description. Until then, leave the "not available" line in.
- [ ] If an in-site practice box exists, say what it costs in allowance terms, in language a learner can see. Do not promise unlimited use.
