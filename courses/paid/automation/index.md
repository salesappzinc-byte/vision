# Paid path draft: one repeating task, on paper

**Status:** Written draft, 8 November 2026. Not recorded. Not for sale.

**Audience:** someone with a weekly task they can describe. Beginners. File sorting is a module inside this path, not a separate course.

**Prerequisite:** free gateway weekly map.

**Tool cost:** an automation product, if you later connect one, is your cost and is not required here. This path does not connect email, files, or payments.

**Lessons:** [01 Name the task](01-name-the-task.md) is script-ready. [Lessons 2 to 5](lessons.md) are notes, not recordings.

**Project:** a written recipe: trigger, input, action, human approval, error handling, and what you will not connect. Nothing runs.

**Rubric:** a person is named in approval; no live connection; no claim that time or money was saved; file names in the sample are labels, not your real archive.

**Quiz:** end of [lessons.md](lessons.md).
