# Automation path lessons 2 to 5

**Status:** Teaching notes, 8 November 2026. Not recorded. Not for sale. Nothing in these notes should be switched on.

Lesson 1 is [01-name-the-task.md](01-name-the-task.md).

## Lesson 2. Trigger and input

**Teach:** A trigger is the moment you start, such as Monday on your calendar. An input is what you gather yourself. A tool must not be the thing that starts the task in this course.

**Exercise:** Write the trigger and two inputs. Use labels, not real file names from your computer.

**Prompt:** `Rewrite my trigger so it is started by me, not by an app. TRIGGER: [paste]`

**Artifact:** those three lines.

**Check:** no phrase like "when an email arrives, send a reply".

## Lesson 3. Action and a person

**Teach:** The action is the draft you ask a chat page to write. The person reads it before it leaves the notebook.

**Exercise:** Write the action as one request. Name the person (you, unless you have asked someone else).

**Artifact:** action plus name.

**Check:** the approval line is not "the AI approves".

## Lesson 4. Files, as labels only

**Teach:** Sorting files can be part of this task. In the exercise, use pretend names: Folder A, Folder B. Do not point a tool at your real documents. Do not upload a archive of your disk.

**Exercise:** Write three pretend file labels and the folder you would put each in, on paper.

**Prompt:** `Given only these labels, suggest a folder name for each. Do not invent extra files. LABELS: [paste]`

**Artifact:** the three rows.

**Check:** no real path such as a home directory appears.

## Lesson 5. When it goes wrong

**Teach:** If the tool is down, you do the task yourself. If a new name appears, you delete it. If you are unsure, you stop. You do not buy a connector to "finish the exercise".

**Exercise:** Write those three error lines under the recipe. Sign the shared approval line.

**Artifact:** the full recipe.

**Check:** the [path rubric](index.md). No account was connected.

## Quiz

1. Who starts the task in this course?
2. What do you do if the draft names a person you did not type?
3. May you point the tool at your real files for this exercise?

**Key:** 1. You do. 2. Delete that name. 3. No.
