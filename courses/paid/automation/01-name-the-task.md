# Lesson 1. Name one task you already repeat

**Status:** Script-ready draft. Not recorded. Not for sale.

**Objective:** Describe one weekly task in a single sentence that a stranger could follow, without turning anything on.

## Teach

Automation starts as a sentence, not a switch. "On Monday I look at three labelled folders and write which one is still on the desk" is a task. "Save me time" is not.

Use your gateway map if you have one. If the old map tried to send mail, cross that out. This lesson does not send mail, move files, or buy anything.

Sam's sample stays fictional and is not bookkeeping advice. Nia's sample is "When I sit down with paper, I rewrite the six lines about the book swap and delete any date I did not choose."

## Exercise

1. Write the one sentence.
2. Run the prompt.
3. If the reply tells you to connect an account, delete that line and note it on the [edit log](../../shared/worksheets.md).

## Prompt

```
Restate my task in one sentence.
Then list trigger, input, action, human approval, and what to do if you are unsure.
Do not tell me to connect email, files, or payments.
Do not say this saves time or money.

TASK:
[paste your sentence]
```

## Artifact

The sentence and the five lines, marked "not connected".

## Check

A person, not the tool, is named as the one who approves. You did not sign in to an automation product for this lesson.
