# Website path lessons 2 to 5

**Status:** Teaching notes, 8 November 2026. Not recorded. Not for sale.

Lesson 1 is [01-plan-the-pages.md](01-plan-the-pages.md). Worksheets: [shared sheet](../../shared/worksheets.md).

## Lesson 2. Words, then a rough layout

**Teach:** Write the home sentence and the "will not claim" line before you pick a colour. A box on paper labelled Header, Main, Contact is a layout.

**Exercise:** Sketch one page. Put the real sentence in the main box.

**Prompt:** `Suggest a simple order of blocks for this page. Do not add a review block. PAGE SENTENCE: [paste]`

**Artifact:** the sketch.

**Check:** the sketch has your sentence, not a slogan you did not write.

## Lesson 3. Pick a way to build

**Teach:** You may use a no-code builder or an AI builder. This course names neither as required. If you open one, copy its name and version onto the tool line. If you buy nothing, stay on paper.

**Exercise:** Write one sentence: "I will use [name] " or "paper only today".

**Artifact:** that sentence plus the tool line if a tool was opened.

**Check:** you did not start a paid checkout for the exercise.

## Lesson 4. Make the pages match the plan

**Teach:** Build only the pages from lesson 1. If the tool adds a blog, store, or review widget, remove it.

**Exercise:** Create the pages in the tool or on paper. Add a text alternative for any picture: "Sample tin on a desk" is enough for a sample.

**Prompt:** `List the pages I asked for and the text I gave. Flag any extra page. PAGES: [paste]`

**Artifact:** preview link you opened, or photos of the paper pages.

**Check:** page count matches the plan.

## Lesson 5. A privacy note and a stop

**Teach:** If a page asks for a name or email, say what you will do with it in one plain paragraph. This is a starter, not a law for every country. If you are unsure, do not collect the address yet.

**Exercise:** Draft that paragraph. Read it. Do not connect a payment button.

**Artifact:** the paragraph and the rubric items ticked by you.

**Check:** no fake review, no traffic number.

## Quiz

1. What do you write before colours?
2. Who pays for a builder if you choose one?
3. What do you do with a review widget you did not plan?

**Key:** 1. The page jobs and the sentences from your brief. 2. You do. It is not a course fee. 3. Remove it.
