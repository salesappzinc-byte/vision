# Lesson 1. Plan the pages before the pictures

**Status:** Script-ready draft. Not recorded. Not for sale.

**Objective:** List three to five pages and the one job of each, using only your brief.

## Teach

A site that starts with colours usually hides a missing sentence. Start with the jobs. A home page says what this is. A details page says who it is for and what you will not promise. A contact page says how a person reaches you, even if the method is "not set yet".

Sample, fictional: Sam's folder notes do not need a shop. The pages can be Home, How the list works, and Contact. Nia's book swap can be Home, What to bring, and Contact. Neither page says a library agreed.

Do not invent a testimonial block. If you have no quote, the page has no quote.

## Exercise

1. Write the page names and one sentence each.
2. Run the prompt.
3. Delete any page you do not need, and any claim you did not write.
4. Log the edit on the [shared sheet](../../shared/worksheets.md).

## Prompt

```
Using only the brief below, propose 3 to 5 pages.
For each page give a name and one sentence.
Do not add prices, reviews, savings, or a claim that a place has agreed.
If a fact is missing, write "not stated".

BRIEF:
[paste]
```

## Artifact

A page list in your notes. Not a live site yet.

## Check

Every sentence traces to the brief. Contact does not include a real private address unless you chose to publish it outside this exercise. This exercise uses "not stated".
