# Theme spec (provisional)

**Brand:** Clearpath is a working name, not a locked brand. 8 November 2026.

**Inspiration, not a copy:** Seedance's public model page (https://seed.bytedance.com/en/seedance2_5) and Higgsfield's about page (https://higgsfield.ai/About), both read 8 November 2026. We take the idea of a calm production surface and a visible result. We do not take their logos, layout, photography, or marketing numbers.

**Surfaces:** lesson reading stays light (`--color-a-fog` page, white cards, navy ink). Creator workspace uses a dark frame (`--color-a-ink` background, white text, sea accent only on the status pill). One accent, not a neon palette.

**Type:** Newsreader for titles, IBM Plex Sans for UI. Already in the mock. Body size stays at least 14px.

**Credibility:** show the real lesson name, a draft label, and a tool-cost warning. No fake ratings, user counts, or testimonials.

**Learning tone:** plain and guided. A free first win, then a paid project the person can decline, then an optional later skill. No earnings countdown and no locked next step. The mock was not restyled in the outline pass.

**What is on screen:** `a-course-detail-mobile.html` is a static course frame. `a-creator-workspace-mobile.html` is a static review queue. Neither accepts a file or plays video.

**Contrast:** body copy is ink on white. Dark workspace copy is white on ink. The muted grey is for secondary labels only. This is not a finished accessibility audit.

Uncommitted design files outside this checkout were not inspected.
